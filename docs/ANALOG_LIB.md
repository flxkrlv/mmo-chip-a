# Analog library — параметрические аналоговые приборы

Аналоговая библиотека mmo-chip-a: набор **параметрических приборов** (pcell),
которые раскладываются по слоям из параметров, а не рисуются руками. Инструмент
в die viewer: **Place analog device**.

Прибор кладётся на кристалл как обычная ячейка — со всеми слоями (диффузия,
поли, контакт, металл, колодец, маркер), поэтому штатный экстрактор видит в ней
тот же прибор, что и в ячейке, нарисованной вручную.

---

## Что в библиотеке

| Шаблон | Что это | Слои |
|---|---|---|
| `pmos` | p-канальный MOS в n-well | `nwell`, `diffusion` (p+), `polysilicon`, `contact`, `metal1` |
| `nmos` | n-канальный MOS в p-well | `pwell`, `diffusion` (n+), `polysilicon`, `contact`, `metal1` |
| `npn` | вертикальный NPN | `npn_id`, `base`, `emitter`, `collector`, `contact`, `metal1` |
| `lpnp` | боковой PNP | `lpnp_id`, `emitter` (p+), `collector` (p+, кольцо), `bulk` (n-база), `contact`, `metal1` |

Вертикальный **PNP** пока убран: экстрактор не умеет vpnp, ячейка отложена
(вернёмся, когда появится поддержка).

Параметры:

* **W**, **L** — в микрометрах, на **один** палец (finger);
* **fingers** — число пальцев (параллельных транзисторов) внутри одной структуры;
* **multiplier** (только MOS) — сколько копий структуры стоит рядом;
* **mult. gap** (только MOS) — зазор между копиями;
* **bulk** (только MOS) — `none` (колодец без контакта) или `tap` (контакт в
  колодце, вне диффузии прибора);
* **emitter–collector** (только BJT) — расстояние от эмиттера до коллектора;
* **emitter–base** (только NPN) — базовый материал от эмиттера до края базовой
  области;
* **collector–base** (только LPNP) — базовый материал от кольца коллектора до
  края базовой области (там базовый контакт);
* **base contact** (только BJT) — с какой стороны сидит контакт к базе:
  `left` / `right` / `top` / `bottom`.

У NPN дефолты отодвинуты подальше: `emitter–base` = 1 мкм,
`emitter–collector` = 2 мкм (коллектор не примыкает к базе).

Правила раскладки (spacing, poly overhang, размер контакта, поля колодца,
поле базы, ширина коллектора, зазоры LPNP и NPN) — в
`shared/src/analogLib.ts` (`DEFAULT_ANALOG_LIB_RULES`), в микрометрах.

### Мультипликатор (MOS)

`multiplier` кладёт **M копий структуры рядом** (вдоль оси тока), между
копиями — зазор `mult. gap`; у каждой копии своя полоса диффузии, свои
затворы, свой strap и свои контакты. Всё это — в одном колодце.

> Электрически копии стоят **последовательно** (ток течёт вдоль полосы), а не
> параллельно. Для параллельного массива копии кладутся в ряд по другой оси
> (в классической раскладке — вертикальные полосы под общим полизатвором) —
> это уже не укладывается в «структуру + зазор», поэтому сделано как сделано;
> дальше слои правятся руками.

### Прибор целиком лежит в своей ячейке

Генератор считает границы всех своих фигур и сдвигает их так, чтобы они
начинались с нуля: **ячейка = рамка прибора**, ничего не торчит за её край.
Проверено тестом на всех шаблонах и обоих числах пальцев.

### LPNP: эмиттер в базе, коллектор кольцом

```
   n-база (слой bulk)
   ┌──────────────────────────────────────┐
   │        ┌────────────────────┐        │   ← кольцо коллектора (p+)
   │        │  ┌──────────────┐  │        │
   │        │  │ p+ эмиттер   │  │        │   ← эмиттер (p+)
   │        │  └──────────────┘  │        │
   │        └────────────────────┘        │
   │             o ← контакт к базе       │
   └──────────────────────────────────────┘
```

База бокового PNP — это n-область, в которой лежат эмиттер и коллектор,
поэтому она раскладывается в слой `bulk`: именно по нему экстрактор
находит базовый контакт (слой `base` тут не нужен, иначе прибор перестал бы
считаться боковым). Эмиттер при этом целиком внутри базы, поэтому площадь
перекрытия «база ∩ эмиттер» = площадь эмиттера ⇒ **AE** = площадь эмиттера,
**PE** = его периметр, `multiplier` = число эмиттеров.

## Масштаб

* **Единица библиотеки analogLib = 1 мкм.**
* `DieSummary.cellScale` («lib scale» в свойствах кристалла) — **масштаб
  библиотеки по умолчанию**: пикселей на library unit. Для analogLib это
  пиксели на микрометр.
* `Cell.scale` — **собственный масштаб элемента** (пикселей на library unit).
  Если его нет — берётся масштаб кристалла. Элемент может отличаться от
  библиотечного: один кристалл — элементы разного размера.
* `CellType.pcell` — спека прибора (`template`, `params`, `scale`, `rules`),
  по которой он был сгенерирован.

Как это считается при отрисовке — `cellInstanceScale()`
(`frontend/src/lib/cellFootprint.ts`):

```
pcell-тип:      factor = cell.scale / pcell.scale   (у сгенерированного = 1)
обычный тип:    factor = cell.scale / cellScale(кристалла)
```

Растяжение заготовки (угол мышью) — это множитель `k`; при accept прибор
генерируется уже на итоговом масштабе (`scale × k`), так что слои клетки —
финальная геометрия, и экстрактор считает по ним верные W/L.

> Чтобы извлечённые W/L совпадали с параметрами, масштаб должен равняться
> `1 / umPerPx` (калибровка кристалла по линейке). В панели тула есть кнопка
> «scale = µm/px», которая ставит его автоматически.

## Геометрия: почему именно так

Экстрактор считает канал как **пересечение** gate-poly и диффузии, поэтому
раскладка подчинена этому.

### MOS

```
        ┌──── poly strap (gate bar) ────┐   ← связывает пальцы
        │   ┌───┐         ┌───┐         │
   ─────┼───┤ G ├───┬─────┤ G ├───┬─────┼───  ← diffusion (одна полоса)
        │   └───┘  │     └───┘  │     │   │
        └──────────┴────────────┴─────┴───┘
                    S        D/S        D
```

* **Диффузия** идёт вдоль оси gate-to-gate, полосой высотой `W` (ширина
  канала) и длиной `N·L + (N+1)·spacing`.
* **Gate-бары** поперёк: ширина `L` (длина канала), высота `W + poly overhang`.
  Пересечение бара с полосой = `L × W` — ровно канал.
* **Один палец = один gate-бар.** Экстратор режет диффузию по каждому gate
  (`splitDiffusionAtGates`) на `N+1` сегментов и назначает их S/D по
  чередованию — так и строятся терминалы.
* **Пальцы соединены poly-strap'ом.** Экстрактор группирует gate-нет по
  пересечению полигонов; без strap'а у каждого пальца был бы свой gate-нет.
* Контакты: по одному в каждой S/D-области, один на strap'е (gate), плюс
  опциональный well tap (bulk) — вне диффузии, внутри колодца.

### BJT

* **Маркер** (`npn_id` / `pnp_id` / `lpnp_id`) — рамка прибора; экстрактор
  берёт из неё `collector`, `base`, `emitter`.
* **AE** = площадь пересечения `base` и `emitter`; у **lpnp** базы нет, поэтому
  AE = сырая площадь эмиттера.
* **PE** = периметр эмиттера.
* `multiplier` = число эмиттерных полос, `emitterFingers` — то же.

## Как этим пользоваться

**Клавиша `I`** открывает вкладку **Lib** в правой панели (и разворачивает
панель, если она свёрнута). Повторное нажатие возвращает вкладку Inspector.

В панели:

1. выбрать прибор (PMOS / NMOS / NPN / LPNP) — сверху **превью** слоёв;
2. задать **W**, **L**, **fingers**; для MOS — **multiplier** и **mult. gap**,
   для BJT — **emitter–collector**, **emitter–base** / **collector–base** и
   сторону **base contact**;
3. задать **масштаб** (px/µm) — кнопка «scale = µm/px» ставит его по
   калибровке кристалла;
4. повороты / отражения — кнопками (в тулбаре для этого места нет);
5. **Place** — вооружает инструмент размещения на кристалле.

Дальше на кристалле: клик — заготовка появляется, угол мышью растягивает её
поверх транзистора в фото, **Enter** кладёт клетку. **Esc** — отмена.

Кнопка в тулбаре (`Place analog device`) только вооружает инструмент —
параметры живут во вкладке Lib.

## Свойства и дальнейшая правка

* Последний использованный прибор (шаблон, параметры, масштаб) запоминается в
  `preferences` (`analogCellLast`) — следующий начинается с тех же настроек.
* Размещённый прибор — **обычная ячейка**: её слои правятся в Cell RE как
  обычно; тип у неё уникальный, библиотечная заготовка не затрагивается.
* В инспекторе у прибора есть строка «edit parameters» — она возвращает прибор
  в тул, и он перекладывается заново (ручные правки слоёв при этом
  теряются — об этом предупреждает подсказка).

## Проверка

`frontend/src/lib/analogLib.test.ts` прогоняет сгенерированные приборы через
родной экстрактор (`detectMOSFromLayers`, `extractMarkedDevices`) и проверяет,
что на выходе получаются правильные приборы:

* pmos / nmos — правильные `mosType`, `W_um`, `L_um`, набор терминалов
  D/G/S/B, по устройству на палец, **один общий gate-net** на multi-finger,
  well tap только по запросу;
* npn — правильный `kind`, `AE_um2`, `emitterFingers`, набор терминалов B/C/E;
* lpnp — эмиттер внутри кольца коллектора, база (слой `bulk`) вокруг, и тоже
  распознаётся как `bjt_pnp` с правильной площадью эмиттера;
* **все приборы целиком помещаются в свою ячейку** (границы ячейки = границы
  прибора).
