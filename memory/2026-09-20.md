# LVS name-based: отдельное окно Unbalanced Nets + resizable/collapsible секции

## Задача
Для name-based движка LVS добавить отдельное UI-окно вывода unbalanced nets:
заголовок цепи, затем строки `Device electrode...` (устройства по алфавиту,
электроды по возрастанию, реальные индексы — включая симметричные R/C/L).
Существующий report (backend + UI) НЕ трогать. Property Diffs / Device Diffs /
новое окно — resizable (CSS `resize: both`, ширина+высота) и collapsible,
с персистом в localStorage.

## Backend
- backend/src/lib/compareByName.ts: `NetConnection` + `buildNetConnections`
  (реальные индексы электродов для всех типов; устройства — natural sort,
  электроды asc); в результат добавлено `netConnectivity {layout, schematic}`
  только для unbalanced цепей. Матчинг/вердикт/report не тронуты.
- shared/src/types.ts: `LvsNetConnection`, `LvsNetConnectivity`,
  `LvsRawResult.net_connectivity?` (опционально).
- backend/src/api/lvs.ts: `nameBasedToRawResult` прокидывает `net_connectivity`;
  `runNameBasedEngine` (report) НЕ изменён.

## Frontend
- frontend/src/components/netlist/ResizableSection.tsx (новый, CRLF):
  caret-заголовок (сворачивание) + body с `resize: both`; размер/состояние в

## Unbalanced Nets / Compare: авто-пара, тёмные селекты, стрелки, разделители строк
- Авто-сопоставление: пара определяется внутри class-группы по индексу
  (class.a[i] <-> class.b[i]). При выборе layout-нета справа автоматически
  подставляется парный schematic (или пусто, если пары нет) и наоборот. Состояние
  cmp*Net: `undefined` = не выбрано (дефолт), `null` = явно пусто.
- Селекты неты: фон `var(--card)` (как фон программы) + `colorScheme: dark`,
  текст `var(--fg)`; у option тоже тёмный фон/контрастный текст.
- Рядом со селектами — стрелки ◀ ▶ для последовательного переключения (с
  закольцовкой), отдельно для Layout и Schematic; переключение тоже авто-парит.
- Строки таблицы Compare разделены тонкими серыми линиями (`1px solid var(--l2)`
  сверху/снизу каждой td, header — borderBottom), как в таблице.
