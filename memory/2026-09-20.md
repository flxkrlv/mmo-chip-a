# LVS name-based: отдельное окно Unbalanced Nets + resizable/collapsible секции

## Задача
Для name-based движка LVS добавить отдельное UI-окно вывода unbalanced nets:
заголовок цепи, затем строки `Device electrode...` (устройства по алфавиту,
электроды по возрастанию, реальные индексы — включая симметричные R/C/L).
Существующий report (backend + UI) НЕ трогать. Property Diffs / Device Diffs /
новое окно — resizable (CSS `resize: both`, ширина+высота) и collapsible,
с персистом в localStorage.

### Fix: bulk (B) всегда уходил на GND
- Баг: B у MOS всегда подключался к GND/VDD, даже если к bulk-контакту шёл
  другой нет. Причины:
  1. `resolveDeviceContacts` (simpleAnalog.ts) для B исключал контакты на ЛЮБОМ
     diffusion (`mosOtherLayers` = все слои D/S/G) → настоящие well/bulk-tap
     контакты (обычно на diffusion) не попадали в termContacts B.
  2. `_processOneCellType` (dieWideAnalog.ts) при `t.netId < 0` безусловно
     подставлял supply, не проверяя провод.
- Фикс:
  1. B-исключение теперь по shape-id конкретного девайса: исключаются только
     контакты внутри ЕГО D/S-сегментов и gate-poly (`bExcludeShapeIds` +
     `shapeById`), а не любой diffusion.
  2. Новая ветка B в `_processOneCellType`: сначала `matchWireToPoint` по
     termContacts[B] — если провод есть, берём ЕГО net; если ничего не
     подключено, только тогда GND (NMOS) / VDD (PMOS).
- Проверки: frontend tsc 0, vite build OK, vitest 155/155, CRLF сохранён.
