# 2026-07-02

## Functional Block Diagram — реализация

- **Новый файл:** `frontend/src/lib/schematic/blockDiagramFormat.ts`
  - Генерирует Yosys JSON для блок-диаграммы по floorplan-регионам
  - Каждый регион → `sub_odd`/`sub_even` прямоугольник с I/O портами
  - Direction портов инферится по gate/non-gate терминалам
  - IO пины → `inputExt`, VDD/GND → `vcc`/`gnd`
  - Layout: RIGHT, через тот же `buildSkin()`
- **Изменён:** `SchematicViewPanel.tsx` — кнопка Analog/Functional, все UI контролы работают в обоих режимах
- **Изменён:** `netlist2svgSkin.ts` — добавлены `block_odd`/`block_even` типы (пока не используются), исправлены `sub_odd`/`sub_even`
- **Изменён:** `Netlist2SvgView.tsx` — `fixBlockLabels()` пост-процессинг для имён блоков (через `$cell_id` в CSS классе)
- **Unassigned устройства** рисуются аналоговыми символами рядом с блоками (через параметр `unassignedDevices`)

## Исправления в процессе:
1. ELK crash на `block_odd`/`block_even` (Referenced shape does not exist) → вернул `sub_odd`/`sub_even`
2. Подписи блоков не работали (`s:attribute="ref"` не заменяет текст) → `fixBlockLabels()` пост-процессинг
3. Unassigned устройства рисовались generic'ом → фикс alias-имён (nmos_v, pmos_v, q_npn, r_v, etc.)

## BJT и резисторы — доработки
- `netlist2svgFormat.ts`:
  - `bjtAttributes()`: на схеме только `M=x`, в `_detail` — NPN/PNP, AE (NPN) / PE (PNP), M
  - `resistorValueString()`: многострочный value с сопротивлением, квадратами, типом (poly/base/film)
- `netlist2svgSkin.ts`: добавлен `<text s:attribute="value">` к NPN/PNP
- `blockDiagramFormat.ts`: те же фишки для unassigned устройств
- `Netlist2SvgView.tsx`: `annotateDeviceData()` читает `_detail` для тултипов

## Баги
- `s:attribute="ref"` не работает для `sub_*` типов в netlist2svg — нужен пост-процессинг
- Compaction ломает рендер при value-тексте на схеме
