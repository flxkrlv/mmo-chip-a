### Cross-tab navigation
- **Analog Netlist → Die Viewer**: double-click device → URL params `?focusCell=&focusDevice=` → камера фреймит cell + выбирает device (чинил retry с setTimeout когда canvasHandle ещё null)
- **Die Viewer → RE Cell**: double-click на любом cell на die (Q10 или rect) — проверяет hitTestAnalogDevice, затем annotationLayer.hitTest для cell annotations
- **Die Viewer → RE Cell**: 🔗 иконка в OutlineTree (items panel), передаёт cellTypeId + cellId
- Горячие клавиши `1`-`5` для переключения вкладок (NAV_HOTKEYS + NavigationHotkeys в App.tsx)

## Архитектурные решения
