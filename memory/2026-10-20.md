## CV/template: `Visible image source not found`

- Причина регрессии: коммит `f6777df` (tiled overlays) заменил прямое
  `path.join(overlay-images/<die>, overlayFilename)` на
  `resolveOverlayOriginalPath`, который умел только manifest-backed tiled
  источники (`SAFE_ID` + `manifest.json`). Legacy-overlay (`me2.png` и т.п.)
  отбрасывался, поэтому CV/ML отдавали 404, хотя верхний видимый слой был
  именно legacy-файлом.
- Фикс в `backend/src/api/overlayImages.ts`: resolver сначала пробует manifest,
  затем (если абсолютный `originalPath` устарел после переноса проекта) файл
  рядом с манифестом, затем безопасный legacy-файл из per-die overlay dir.
- Регрессионный тест в `backend/src/app.test.ts` ("overlay source resolution
  accepts legacy filenames and tiled ids"); `npm run build -w backend` и тест
  проходят. Полный `app.test.ts` содержит известные падения:
  `analyses a supplied circuit snapshot` (502 до фикса), TIFF-prebuild EBUSY.
