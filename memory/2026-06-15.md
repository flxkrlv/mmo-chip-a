### SPICE exporter quality pass
- Сравнил с реальными Spectre нетлистами из OPA547 и FD6288.
- **MOS**: только w/l/m (убраны AS/AD/PS/PD, убран NF/fingers).
- **BJT**: только m (multiplier). Нормализация: ищем минимальный AE для NPN,
  минимальный PE для PNP → это m=1, остальные масштабируются.
- **Резисторы**: `r=<Ω>` (squares × sheetR), без W/L/TYPE.
- **Spectre формат**: пассивы и BJT используют type-ключевые слова
  (`resistor`/`capacitor`/`npn`/`pnp`) вместо model name.
- **Model cards**: не генерируются по умолчанию (пользователь подключает .scs
  в Cadence).
- **Параметры**: SheetR сохраняется в комментарии для справки.
