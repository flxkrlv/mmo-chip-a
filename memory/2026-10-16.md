- api/tiles.ts: serveCrop body extracted into exported renderDieCrop (reused by get_die_image). overlayImages listManifests exported.
- Frontend: InspectorTab "mcp" + McpPanel (endpoint URL, `claude mcp add` line, JSON config incl. Bearer token if logged in; mode chips; history with Undo/Redo, refreshed via annotation WS events). vite proxy /mcp → :3001.
