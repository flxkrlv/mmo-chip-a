## RNL: secure context, full viewer, theme (mmo-chip-a)

- Ошибка `analog-canvas-extensions 0.7: Cannot read properties of undefined
  (reading 'digest')` воспроизведена в Chrome: встроенный iframe с
  `rich-netlist.github.io` внутри страницы `http://192.168.0.108:…` получает
  **небезопасный контекст**, `crypto.subtle` = undefined, а viewer проверяет
  SHA-256 пакета. На `http://127.0.0.1` и HTTPS всё работает.
- Вывод: viewer нельзя чинить копированием — копия того же статического
  Rust/WASM-приложения на HTTP-LAN упадёт так же. Копировать legally можно
  (viewer MIT, fonts OFL), но не нужно.
- Решение: на secure-странице — встроенный canvas (`embed=1`); иначе —
  **Full viewer ↗**, который открывает полный `rich-netlist.github.io/rnl/viewer/`
  через `api=1&origin&token`, ждёт `ready` (features requestId/packages) и
  отправляет `open` с текстом и `analog-canvas-extensions` — без clipboard.
  Проверено Playwright'ом с insecure-родителя: popup secure, `crypto.subtle`
  есть, пакет загружен, `loaded errors=0`.
- В RNL-вкладке textarea теперь `var(--card)` / `var(--ink)` (тема приложения,
  без синего fallback `#11151b`), шрифт 13px/1.55.
- MCP: `rnl_read` / `rnl_write` зарегистрированы в `EXTENDED_TOOLS`, тест

## RNL snapshot workflow: pin, overwrite confirmation, history (2026-11-21, вечер)

  пере-экспортировала его и затирала правки агента без следа.
- `backend/src/rnlStore.ts`: версии в `rnl/history/<module>/` (`index.json`
  + `<rev>.rnl`), состояние в `rnl/<module>.state.json`. У версии есть
  author (schematic/agent/user/saved), note, added/removed, baseRevisionId,
  restores, unchanged. Файл без истории усыновляется как `saved` при первой
  записи. Хранится 100 версий, baseline не удаляется.

  при edited без `confirmOverwrite`. После подтверждения старый рисунок
  остаётся в истории.
- API: `GET/PUT .../rnl` (+state), `PUT .../rnl/state` (frozen),
  `GET .../rnl/history`, `GET .../rnl/history/:id`,
  `POST .../rnl/history/:id/restore`. Restore создаёт новую версию user с
  `restores`.
- MCP: `rnl_write` принимает `note` и возвращает revision/state/
