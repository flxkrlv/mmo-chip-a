# 2026-10-27 —-desktop-бинарь

Задача: бинарная сборка mmo-chip-a без внешних зависимостей (Electron, ML — опционально, ngspice+vyges в бандле, win+linux).

## Решения (подтверждены юзером)
- Electron (оболочка), frameless/минимальная рамка → drag-зона + свои кнопки окна.
- ML sidecar в бинаре: опционально, ставится позже кнопкой (пакдоступ).
- Бандлить нативные бинарьки сим (ngspice_con, vyges-lvs) в ресурсы, пользователь ничего не ставит.
- Платформы: win + linux.
- Архитектурный трюк: бэк запускается как child манообразующий process.execPath по предложению `ELECTRON_RUN_AS_NODE=1` → всё работает как обычный Node; ресурсы в resources/app маппированы как repo (backend/dist, shared, frontend/src? dist, scripts/netlist-export.ts, node_modules prod+tsx+clipper2-wasm) — self-spawn netlist-export работает без переписывания.

## Грабли дня (запомнить)
1. Inline object key `clipper2-wasm:` в .mjs — SyntaxError; ключи с дефисом в объектных литералах кавычить.
2. Node 24 отказывает type-stripping в node_modules → запускать с `--import tsx` (в т.ч. бэкинг в Electron шансомина).
3. В агентской песочнице electron.exe получает EPERM на запись в C:\Users\* — поэтому упал и crashpad («not connected») и окно молча гасло; на машинах пользователей этого нет. Everything на F: работает.
4. NGSPICE требует lib/ngspice/*.cm рядом (..\lib) и TMPDIR — Spice64 tree копировать целиком (bin+lib+share).
5. NSIS (makensis 3.0.4.1) падает «Internal compiler error #12345 … mmap» на билд-содержимом ~111MB → win target = zip; NSIS можно вернуть в CI.
6. SourceForge фетч флакует → ретраи обязательны.
