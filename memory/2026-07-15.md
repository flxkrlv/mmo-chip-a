## Connectivity Rules
- Wire tool snapNode: different metals only connect via matching via annotation
- AutoVia (checkbox): when enabled + adjacent metals, via auto-placed on cross-metal snap
- Terminal snap: only on bottommost metal (ME1)
- Via layer: stamped on placement, used for color rendering, inspector display, snap filtering
