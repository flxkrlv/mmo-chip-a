## uuid polyfill (`frontend/src/lib/uuid.ts`)

`crypto.randomUUID()` не работает через Network IP (10.x.x.x) — не secure context.
Добавлен `uuid()`: пробует `crypto.randomUUID()`, при ошибке — полифилл UUID v4 на `Math.random()`.
Заменены все `crypto.randomUUID()` → `uuid()` в 4 файлах.

## Cell flicker на localhost (`frontend/src/api/actions.ts`)

При создании cell на localhost: cell появлялся → исчезал на ~500ms → появлялся снова.
**Причина:** race condition — WebSocket пуш от бэкенда приходил раньше HTTP-ответа на localhost, вызывая двойной `invalidateQueries` из `finally`. На network HTTP-ответ приходил первым, второй invalidate отсекался чеком `current.rev >= msg.rev`.

**Фикс:** убран `invalidateQueries` из `finally` в `useActionDispatcher`. На консистентность не влияет — WebSocket handler или `refetchOnWindowFocus` подтянут данные.

## BJT terminal assignment fix (`frontend/src/api/dieWideAnalog.ts`)

У NPN на оверлее die viewer оба контакта подписывались как "B" (база).
**Причина:** эмиттер внутри базы → контакт на эмиттере пересекался с обоими слоями (base+emitter) через `rectsOverlap`. Round-robin отдавал контакт B (первый в сигнатуре "B,E"). E оставался без подписи.

**Фикс:**
- Добавлен `pointInShape(px, py, shape)` — для rect, polygon (ray casting), circle, point, line
- `termPoints`: переписан на итерацию по контактам + point-in-shape + приоритет BJT (E > C > B)
- `cTis` (wire matching): два пути — `allSameLayer` (R/C/D: старый rectsOverlap) и BJT/MOS (point-in-shape + priority)
- Netlist extraction (`simpleAnalog.ts`) не тронута — там dummy net IDs генерируются корректно

## Overlay images на Merge Canvas + RE Cell Canvas

### Store (`frontend/src/state/overlayLayers.ts`)
- Добавлено `baseImageVisible: boolean` (default true) + `toggleBaseImage()`

### Hotkeys (`frontend/src/lib/useOverlayHotkeys.ts`)
- **Ctrl+Shift+B** — toggle base image visibility (die photo / cell crop)
- **]** — соло-показ следующего overlay слоя (N+1), остальные скрыть
- **\[** — соло-показ предыдущего (N-1)
- **Ctrl+Shift+1..8** — соло-показ конкретного слоя (по `e.code`)
- Работают на всех трёх вкладках (Die Viewer, Merge Cells, RE Cell)

### RE Cell Canvas (`frontend/src/components/cellRE/CellRECanvas.tsx`)
- После отрисовки ячейки (crop image) рендерятся overlay images, **clipped to cell area**:
  `drawImage(overlay.image, cell.x - overlay.offsetX, cell.y - overlay.offsetY, box.w, box.h, 0, 0, box.w, box.h)`
- Если `baseImageVisible=false` — crop не рисуется, видны только overlay

### Merge Canvas (`frontend/src/components/mergeCells/MergeCanvas.tsx`)
- В режимах кроме sxs: overlay images рендерятся в world coordinates после отрисовки ячеек
- Подписка на `useOverlayLayers.subscribe` — canvas перерисовывается при изменении overlay слоёв
- `baseImageVisible` не влияет на Merge Canvas (там всегда нужны cell crops для сравнения)

### Die Viewer (`frontend/src/routes/DieViewerPage.tsx`)
- `DieImageLayer.getHidden` теперь проверяет `baseImageVisible || baseImageHidden[die.id]`
- Eye icon в OutlineTree учитывает `baseGlobalVisible`
