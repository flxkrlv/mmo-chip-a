## Настройки ELK в interactive mode
- Проброшены те же селекторы, что у статики: nodePlacement.strategy (BK/INTERACTIVE/SIMPLE),
  direction (DOWN/UP/LEFT/RIGHT), postCompaction.strategy 0-4 (LUT/scanline/sweep/pocket).
  Цифры compaction elkjs 0.11.1 принимает (проверено node-скриптом, 30 комбинаций OK).
- Автодеградация при падении ELK: compaction requested->0, затем BK->INTERACTIVE->SIMPLE,
  потом grid fallback; результат.applied сообщает фактические настройки, UI показывает
  'degraded: X/cN' в статусе. Смена настроек = полный re-arrange (locked остаются).
- Опции ключи: elk.layered.nodePlacement.strategy / elk.layered.compaction.postCompaction.strategy.

## БАГФИКСЫ после Фазы 2 (юзер-репорты)
- **Drag-прыжок вправо/вниз при первом drag**: applyDragPosition ждал delta, но
  onSvgPointerMove передавал АБСОЛЮТНУЮ позицию grab-точки → base+abs удваивал
  координаты. Фикс: applyDragPosition принимает grabAbs и сам считает delta против
  d.base[d.keys[0]] (grabKey), затем применяет к всей группе.
- **Locked устройство пропадает после Re-layout/Auto-arrange**: locked исключены из
  ELK-графа → их нет в elkResult.positions → filtered в nodes. Двойной фикс:
  (1) nodes рендерится по merged `positions` (elk+stored), template-размер для locked;
  (2) runLayout ПЕРЕД ELK делает seedPositions() — персистит текущие рендер-позиции
  locked (без lock-фильтра и без undo-записи), чтобы никогда не двигаемый locked тоже
  пережил re-layout. Store: +seedPositions action.
- **Export PNG не работал**: clone.querySelector("g") попадал в defs (первую группу),
  инверсия фильтр+var(--ink2) в standalone SVG не резолвили → пустая/битая картинка.
  Новый подход: g[transform] (content), bbox из live getBBox, viewBox явный, рекрас
  через CSS !important (stroke:#000) поверх presentation атрибутов, canvas 2x.
- **Mirror/rotate текста устройства (Q14 зеркальный)**: лейблы теперь ВНЕ арт-группы —
  арт (use-символ) внутри `<g transform=rotate+mirror>`, лейблы/рамки/hitbox в
  translate-обёртке → текст всегда горизонтальный и незеркальный.
- Тесты: +1 (seedPositions), suite 83/83, tsc, vite build.
