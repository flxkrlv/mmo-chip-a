## Текущие приоритеты и проблемы

### P0 — Критическое
1. **Нет графического просмотра терминалов / net matching на die view** — пользователь видит netlist, но не может визуально проверить, какие неты к каким терминалам подключены. Overlay termPoint rendering для per-gate устройств — следующий шаг.
2. **Multi-finger MOS contacts**: после разрезания диффузии, контакты на shared сегментах должны соединяться с die-level wires. Сейчас shared сегменты инжектятся через `_segmentShapesCache`, но wire matching для них не тестировался на реальных данных.

### P1 — Важно
3. **Diode multiplier**: extraction ставит `multiplier: 1` всегда. Нужна детекция area ratio как для BJT (по эмиттеру/аноду).
4. **BJT `AE_um2` vs `multiplier`**: сейчас `AE_um2 = totalAE / emitterCount` (per-finger), `multiplier = emitterCount`. С fractional m это соотношение может сбиваться — нужно проверить консистентность.
5. **Resistor W/L для L-образных/meander**: bbox fallback даёт неправильные squares. Calibre использует `PERIMETER_COINCIDE` + `BENDS` — стоит внедрить.

### P2 — Улучшения
6. **Exclusion zones для layer ambiguity**: один слой может означать разные вещи (n_emit → BJT emitter vs capacitor plate). Calibre использует REC-слои.
7. **Unconnected terminal highlighting**: подсветка на die view терминалов с `netId >= 2000` (красный).
8. **Temperature-dependent Rsq**: параметризация sheetR через `.TEMP` в SPICE.
9. **COO (Corner / slow-fast) вариации**: stub для process corners в SpiceConfig.

### Архитектурные вопросы
10. **`assignInstanceNames` вызывается дважды**: в `buildAnalogNetlist()` и внутри `generateSpiceNetlist()`. Работает (порядок совпадает), но не идеально.
11. **matchGeometry модифицирует in-place**: нормально для pipeline, но нужно документировать, что функция мутирует входной массив.
12. **normalizeBJTM vs matching**: matching усредняет AE/PE, потом normalizeBJTM пересчитывает m. Если matching изменяет AE, normalizeBJTM даёт новые m. Это OK, но требует понимания порядка вызовов.
