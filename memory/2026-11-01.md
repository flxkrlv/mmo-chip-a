## Раунд 2 (PlainText spec юзера): 1c = кратчайший путь до вершины/edge нета в бюджете maxBranchLen, иначе snap DROPPED

- После фиксa T-стыка (948906a) юзер: «треугольник» у контактов остался —
  1) провод, почти подошедший к контакту из детекции, 2) остросток от 1c,
  который снапится к контакту, но идёт напрямую (не по металлу) к дальним
  вершинам того же net, хотя рядом есть вершина (1).
- Явный spec юзера: «контакт лежит внутри векторизованного металла → ищем
  КРАТЧАЙШИЙ путь от контакта до вершины или edge в данном net; соединяем
  по кратчайшему расстоянию, НЕ БОЛЬШЕМУ max branch len, иначе откидываем snap».
- Реализация в 1c (два тира кандидатов, выигрывает глобально ближайший):
  - TIER A (как раньше): trace в ТОМ ЖЕ контуре (вершина внутри или сегмент
    строго пересекает край) — ближайшая точка wire (branchAt → T-стык).
  - TIER B (только при maxBranchLen > 0): КОНЦЕВАЯ ВЕРШИНА ЛЮБОЙ трассы,
    без контурного фильтра — «провод, который почти дошёл» (его ось остановилась
    на width-фильтре / на немердженном min-gap блобе) подключается от своего
    конца коротким отростком вместо хорды от далёкой same-contour трассы.
  - Победитель (ties → tier A) гейтится жёстко: winD > maxBranchLen ⇒ SNAP
    DROPPED (новый счётчик outlineDropped, показывается в confirm-диалоге),
    контакт честно остаётся неподключённым вместо хорды.
- Риск noqa: foreign wire конец в бюджете — гейтится тем что он строго ближе
  всего на собственном металле контакта; бюджет = ручка юзера (0 = старое
  поведение, только tier A без капа).
- Тесты 6/6: near-wire-END побеждает далёкую same-contour трассу; snap длиннее
  бюджета отбрасывается (нет ни вершины, ни рёбер у контакта); прежние 4
  (T-стык, проекция на конце, разрез перед концом, group-union сдвиг) зелёные.
  tsc + vite build зелёные.
- NB: тест-хелпер edgeNodes требует резолва нод в СВОЁМ нете (nets[i] порядка
  групп не совпадает с порядком трасс) — дважды на этом спотыкался в тесте.

  plan-пункт «Превью по ROI». Реализовано.
- Sidecar: новый `POST /vectorize/preprocess` (не CV-gated, как /mask):
  multipart image + Form preprocess JSON → apply_preprocess → PNG Response.
  Импорт Response добавлен в fastapi imports.
- Backend: `POST /api/dies/:dieId/vectorize/preprocess-preview`
  (bbox/preprocess/overlaySource из JSON body) — sharp-crop (extract),
  даунскейл ≤1200 px/сторон (точная семантика per-pixel; превью
  advisory-ная), POST у sidecar, ответ image/png. fetchSidecar
  (existing fetchWithTimeout helper) с SIDECAR_RW_TIMEOUT_MS.
- Frontend api: fetchPreprocessPreview(dieId, bbox, params, overlaySource,
  signal) → Blob (fetch POST, authHeaders, ошибка → detail из JSON).
- VectorizeLayer: display.getPreprocessPreview; приватные previewTimer/
  previewAbort/previewKey/previewBitmap(ImageBitmap)/previewBbox;
  schedulePreview() (свой debounce FETCH_DEBOUNCE_MS, key =
  bbox|source|preprocess — НЕ зависит от threshold-параметров; кидает
  из beginFrame после вычисления bbox дажe когда cache-hit);
  drawPreview() — drawImage на bbox-rect (даунскейл растянут обратно)
  + амбер-пунктирная рамка; blит ДО outlines/traces (под всем);
  dropPreview/dropPreviewKeepKey; cleanup в destroy/clearCache.
  Exit-ветка: hidden||!params → drawSaved без превью (подложка только
  для live-декода).
- Стор: vectorPreprocessPreview + setVectorPreprocessPreview
  (transient, reset по die). DieViewerPage: getPreprocessPreview getter
  + effect vectorLayer.refresh() на toggle.
- InspectorPanel: чекбокс «preview processed pixels (live viewport)»
  сразу под заголовком секции Preprocess (tooltip объясняет).
- Проверка: py_compile, backend tsc build, frontend tsc + 477/477 +
  vite build. Нужен рестарт sidecar+backend для e2e (трогает оба).

## Раунд 6 (Phase 2): P2-3 preview v2 — независимо от overlay + реактивные слайдеры

- Юзер: превью не должно быть подложкой vector overlay (работать при
  выключенном overlay), слайдеры должны перерисовывать картинку БЕЗ
  движения канваса.
- VectorizeLayer.beginFrame: schedulePreview вынесен ПЕРЕД hidden-check
  и MAX_AREA_PX guard (превью независимо от 5 Mpx cap live-декода и от
  vectorSweepRunning; нужен только bbox + preprocess + source).
- draw(): drawPreview вызывается ДО `if (hidden || !params)` — превью
  рисуется при выключенном overlay; saved layers поверх.
- Слайдеры: собственный PREVIEW_DEBOUNCE_MS=150 (пользователь таскает
  ползунки). DieViewerPage: preprocessSignature = JSON.stringify(
  vectorParams.preprocess) как селектор; эффект `if (previewOn)
  vectorLayer.refresh()` на изменение сигнатуры — invalidate тайлов,
  beginFrame видит новый preview-key (bbox|source|preprocess) и
  перезапрашивает превью; после получения bitmap'а — invalidateCb.
- Ошибки fetch больше не глотаются: console.warn с.detail (типичная
  причина "превью молча ничего не рисует" — старый sidecar/backend
  без новых эндпоинтов).
- InspectorPanel чекбокс переименован в «preprocess preview (live
  viewport)», tooltip теперь про независимость.
- tsc + 477/477 + vite build — чисто.
